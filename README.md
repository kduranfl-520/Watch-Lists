# Watch Lists

A single-page, tick-off watch list tracker for Marvel, X-Men, DC, Arrowverse, Star Trek, Star Wars, Stargate, Battlestar Galactica, Doctor Who, and Buffy and Angel.

- `index.html` is the whole app. Progress is saved in the browser's local storage.
- `icon.svg`, `apple-touch-icon.png`, `icon-192.png` and `icon-512.png` are the home-screen icons.
- `manifest.webmanifest` lets phones install it as an app.
